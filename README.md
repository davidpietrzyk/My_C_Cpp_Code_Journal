# My_C_Cpp_Code_Journal
Welcome to my personal portfolio, experiment journal, and code showcase for C and C++ projects.

## Setup & Build (Windows + VSCode + MinGW)
I'm developing on Windows with VS Code and MinGW-w64 (will aim for full portability across all my programs in future).

Where to Go to Do the Same
1. VSCode: Download from: [code.visualstudio.com](https://code.visualstudio.com/download)

2. For both Unix and Windows systems: [C/C++ for Visual Studio Code](https://code.visualstudio.com/docs/languages/cpp)

### Why VS Code?
I have used Visual Studio in the past and feel that this lightweight variant is better for the sake of any programs I make. There is no need to hold solutions inside of a more complex folder structure this way. The GitHub extension also means that I have the functionalities I had in standard Visual Studio.

## Extensions installed: 
1. C/C++ (Microsoft)
2. C/C++ Extension Pack (Microsoft)
3. C/C++ Themes (Microsoft)
4. Code Runner (Jun Han)
